# Empire Softball sample

Sample club site for Empire Softball (empiresoftball.org), built 2026-11-20. Plain HTML, CSS and JS, no build step.

- `js/data.js` holds every team, coach, player and event. Teams, coaches, the White 16u Elite roster and the About text are real, taken from their site. Event dates are SAMPLE (marked `sample: true`).
- `js/site.js` renders every page. `css/site.css` is the look (black pinstripe, cream, skyline crest from their own kit).
- Forms are not connected. No admin yet.
- Photos and logo come from their own site.
- Lives in the DVSL repo only as a parking spot; the root `.vercelignore` keeps it off dvsl.vercel.app. Move to its own repo if they sign.
