DVSL → Google Calendar Sync

Reads games from Firebase and creates events in your Google Calendar. Run this whenever the schedule changes.

Setup (one time)

  1. Go to Google Cloud Console → Credentials
  2. Select your Firebase project (dvsl-292dd)
  3. Create an OAuth 2.0 Client ID (Web application type)
  4. Add http://localhost and your Vercel URL to Authorized JavaScript origins
  5. Copy the Client ID and paste it below
  6. Also enable the Google Calendar API in API Library
